# Flow Metrics Analysis

Velocity is supplemented with flow metrics to understand how work moves through the system.

| Metric | Baseline | Final |
|---|---:|---:|
| Median cycle time | 9.1 days | **4.9 days** |
| Blocked-work rate | 17% | **5%** |
| Carryover | 31% | **8%** |
| Throughput | 12 items/sprint | **18 items/sprint** |
| Average WIP | 14 | **8** |
| Items aging >8 days | 11 | **2** |

## Flow Policies
- Review items older than 75% of the cycle-time target.
- Swarm on blocked work threatening the Sprint Goal.
- Avoid starting new work when WIP exceeds the agreed limit.
- Never use flow metrics to rank individuals.
